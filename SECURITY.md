# Security

Toastty is a development preview; no supported stable release has been declared.
Keep local builds current and treat untrusted terminal output and shell commands
with care, as with any terminal emulator.

For a sensitive Toastty vulnerability, use GitHub's private vulnerability reporting
for this repository if enabled. If it is unavailable, contact the maintainer using
the contact method on [dar7an's profile](https://github.com/dar7an) before sharing
exploit details. Do not put credentials, private output, or live exploit details
in a public issue. There is no promised response time at this stage.

Include the affected commit, macOS version, reproduction, impact, and a proposed
fix if available. Coordinate issues in inherited Ghostty code with upstream
privately; do not assume a Toastty issue affects an upstream release.
