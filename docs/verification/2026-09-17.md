# Toolbar, sidebar, and icon verification

Verified locally on Apple Silicon, macOS 27, using `macos/build/Debug/Toastty.app`.

## Changes

- New Tab is a native bordered toolbar item, matching the native sidebar toggle.
  The custom tab rail remains flexible and scrolls when tabs overflow.
- The sidebar material extends through the titlebar safe area behind the traffic
  lights. Its list stays below the toolbar. The horizontal separator is removed;
  the native sidebar material still follows window activity and appearance.
- The toast remains small in the upper-left of a bronze CRT monitor, with butter,
  recessed charcoal bezel, curved glass, and an amber phosphor grid. The icon
  exporter centers its visible alpha bounds at approximately 81% of the canvas.
- Icon updates now refresh the running app directly from the bundled artwork.
  The default uses the compiled icon without writing a Finder custom-icon
  override, which would add metadata that invalidates the app's signature.
  Explicit user-configured alternate icons retain their existing behavior.

## Checks

- `macos/build.nu --action build-for-testing`: passed.
- 31 tests passed across `ProjectWindowLayoutTests`, `ProjectTabStripTests`,
  `TabSidebarModelTests`, and `ToasttyIdentityTests` using the prepared xctestrun.
  Coverage includes the material reaching the window's top, preserved terminal
  height, native toolbar actions, sidebar state, Toastty bundle icon identity,
  and default icon refresh without creating a Finder custom-icon override.
- Strict SwiftLint passed for all seven changed Swift source/test/exporter files.
- `git diff --check`: passed.
- `codesign --verify --deep --strict` passed for the local development bundle,
  including after the icon-refresh test. This is local ad-hoc signing only.
- Desktop checks: New Tab created a tab; sidebar collapse and expansion worked;
  the terminal retained 30 rows; one- and two-tab layouts were inspected in dark
  and light appearance. The light test used a narrower, 70-column window.
- Finder's resolved icon, the compiled `.icns`, and About Toastty were inspected
  after relaunch and show the new CRT artwork. The exported 1024px icon's opaque
  width is 830px (81.1%), close to the upstream icon's 824px (80.5%).

Testing used temporary config files and isolated defaults suites. The development
app was left running in its original dark test configuration. The user's config
was not edited. Direct Dock screenshots were not captured in this pass; Finder
resolution and the app's bundled artwork were checked instead. Older macOS,
Intel, signing/notarization for distribution, and hosted CI remain release checks.
